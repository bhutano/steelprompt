How it works

steelprompt runs as a hook in Claude Code — intercepting every prompt before Claude processes it.

1
You type any prompt
Nothing changes on your end. Write naturally — short, long, technical, vague. steelprompt handles the rest.
2
3-Tier protocol runs
Bypass atomic tasks. Ask one clarifying question if truly needed. Otherwise — apply all 10 Anthropic principles silently before Claude responds.
Bypass → Ask → Apply Framework
3
Claude gets a structured brief
Role · Context + motivation · Task · XML structure · Constraints · Output format · Thinking · Examples · Tool use · Long context.
4
You get a better response
No API calls. No extra tokens. Zero added latency. Claude restructures inline during its normal inference.

Install in 2 commands

Requires Claude Code 2.0.22+ and Python 3.8+

# Add the marketplace
$claude plugin marketplace add bhutano/bhutano-marketplace
# Install steelprompt
$claude plugin install steelprompt
